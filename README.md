# Kafka-MCP
I've been exploring Spring AI by building a small hands-on project that combines Spring Boot, Spring AI, and Apache Kafka.

Instead of manually using Kafka CLI commands or a UI, the application leverages Spring AI Tool Calling to identify the required operation, invoke Spring-managed tools, interact with Kafka, and return a human-readable response.

Tech Stack:

• Java 21
• Spring Boot
• Spring AI
• Apache Kafka (running with Docker)
• Ollama with Llama 3.2 

This project gave me a deeper understanding of how AI can be integrated into existing Spring Boot applications to make backend operations more intuitive and conversational.

It was a great hands-on experience exploring AI-powered tooling with Spring AI and understanding how tool calling works behind the scenes.
